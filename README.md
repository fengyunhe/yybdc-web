# VocabFloat

> 置顶悬浮，背词更轻松

VocabFloat 是一款跨平台桌面悬浮单词学习工具，以置顶悬浮窗的形式在桌面上循环展示单词卡片，帮助你在日常工作和学习中高效记忆英语词汇。

## 功能特性

- **📌 悬浮单词卡片** — 置顶显示在桌面上，不干扰日常操作，随时随地瞥一眼就能背词
- **🔄 自动轮播** — 可自定义切换间隔时间，循环随机展示单词
- **📚 多词本管理** — 内置「朗文3000个常用词汇」和「计算机行业词汇」，支持自定义词本的添加、删除和切换
- **🔍 智能补全** — 添加单词时自动查询翻译、音标和例句，省去手动输入
- **🔊 语音朗读** — 支持 macOS TTS 语音发音，可连续点击排队播放
- **🎨 主题管理** — 内置暗色（Catppuccin Mocha）、浅色（Catppuccin Latte）、跟随系统三套主题，同时支持自定义主题
- **🖼 背景自定义** — 支持设置自定义背景图片
- **📊 学习统计** — 记录每日新学单词数和记忆日期
- **🧠 回忆模式** — 隐藏单词释义，通过主动回忆检测实际记忆情况，巩固薄弱词汇
- **⏸ 灵活控制** — 支持暂停/恢复轮播，鼠标悬停自动暂停，键盘快捷键操作

- **Windows**：下载 `.exe` 文件，双击运行
