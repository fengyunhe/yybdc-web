VocabFloat 隐私策略

生效日期：2026年4月27日

欢迎您使用 VocabFloat（词汇悬浮窗）！本隐私策略旨在向您说明我们在使用这款应用时如何收集、使用、存储和保护您的个人信息。

一、信息收集

我们仅收集为您提供服务所必需的最少信息：

  • 词汇数据：您添加或导入的单词、释义、例句等学习内容
  • 学习记录：已记住/未记住的单词标记、学习进度
  • 应用设置：主题偏好、显示间隔、发音设置等配置信息

二、信息使用

我们收集的信息仅用于：

  • 提供核心学习功能：显示单词、释义、例句，跟踪学习进度
  • 个性化体验：根据您的设置调整界面主题、显示间隔等
  • 学习分析：统计已记住/未记住的单词数量，帮助您了解学习进度

三、数据存储与安全

  • 存储位置：~/.yybdc/ 目录（用户主目录下的隐藏文件夹）
  • 离线使用：本应用完全离线运行，无需网络连接即可使用全部功能
  • 本地保护：数据仅存储在您的设备上，不上传至任何服务器
  • 备份导出：您可以随时导出数据备份或导入恢复

四、第三方服务

本应用的在线功能依赖以下第三方服务：

  • Free Dictionary API (dictionaryapi.dev)：获取单词释义、例句、音标
    • 仅在您主动查询新单词时调用
    • 仅发送您输入的查询单词，不包含其他个人信息
    • 遵循该服务的 Privacy Policy
  • GitHub API：检查应用更新
    • 仅发送版本检查请求，不包含任何个人信息
    • 您的 IP 地址可能被记录用于速率限制

五、语音功能

发音功能使用系统自带语音服务：

  • macOS：使用系统 say 命令
  • Windows：使用系统 SAPI 语音合成
  • 不收集或传输任何语音数据

六、权限说明

本应用无需特殊权限即可运行。桌面悬浮窗功能依赖系统窗口管理权限。

七、变更与更新

我们将通过应用内通知或发布页面告知隐私策略的更新。如有重大变更，我们将明确通知您并获取您的继续使用视为同意。

八、联系我们

如您对本隐私策略有任何疑问，请通过以下方式联系我们：

  • 网站：vocab-float.firegod.cn
